# Lexical Analyzer User Manual

## Overview
This project implements a lexical analyzer (lexer) that processes input files and tokenizes them according to defined rules. The lexer is built using Flex (Fast Lexical Analyzer Generator) and can be used to analyze source code files.

## Prerequisites
- GCC compiler
- Flex (Fast Lexical Analyzer Generator)
- Python 3 (for code generation)
- Make utility

## Installation
1. Ensure you have all prerequisites installed on your system
2. Clone this repository
3. No additional installation steps are required

## Usage

### Building the Project
To build the lexical analyzer, simply run:
```bash
make
```
This will:
1. Generate the C code from the Flex specification file
2. Compile the generated code into an executable

### Running the Analyzer
The project includes a test setup that:
1. Generates a sample input file using the Python code generator
2. Runs the lexical analyzer on the generated file

To run the test:
```bash
make test
```

### Custom Input Files
To analyze your own input file:
1. Create your input file (e.g., `example.ac`)
2. Run the analyzer:
```bash
./lex_analyzer example.ac
```

### Cleaning Up
To remove generated files:
```bash
make clean
```

## Project Structure
- `lex_analyzer.l`: Flex specification file containing lexical rules
- `code_generator.py`: Python script that generates sample input files
- `Makefile`: Build automation file
- `example.ac`: Sample input file generated by the code generator

## Tokens
The lexical analyzer recognizes the following tokens:

| Token | Description | Example |
|-------|-------------|---------|
| `COMMENT` | Single-line comments starting with // | `// This is a comment` |
| `fnum` | Floating-point numbers | `3.14`, `0.5` |
| `inum` | Integer numbers | `42`, `100` |
| `floatdcl` | Float declaration keyword | `f` |
| `intdcl` | Integer declaration keyword | `i` |
| `print` | Print statement keyword | `p` |
| `id` | Identifiers (variable names) | `x`, `myVar`, `counter1` |
| `plus` | Addition operator | `+` |
| `minus` | Subtraction operator | `-` |
| `times` | Multiplication operator | `*` |
| `div` | Division operator | `/` |
| `assign` | Assignment operator | `=` |

The analyzer also handles:
- Newlines (`\n`)
- Whitespace and tabs (ignored)
- Any other characters (ignored)
